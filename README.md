# kirocrew-theme-refresh-e2e

Test fixture. This repository is a throwaway Kiro Crew theme pack used to
verify end to end that an installed theme can be refreshed from its source,
that is, that a new upstream commit is picked up. It is not a theme meant for
everyday use.

Contents: `theme.json` and `variables.json`, a minimal valid Level-0 pack with
slug `refresh-e2e`. The commits after the first one are made by the test run:
an accent colour change, a slug rename, and the slug restored.
